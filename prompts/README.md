# CLAI-OS Prompt Corpus — P51–P110

The CLAI (Clinical Language Artificial Intelligence) prompt registry.
**CLAI prompts exist only in the P51–P110 range** (author ruling 2026-10-12);
the SAVANT FRAMEWORK operations registry (P01–P50) lives in the
`savant-prompts` repository. The two registries are distinct.

## Open tier — AGPL-3.0 (P51–P70): complete artifacts, v2.0

Each file carries the full variant family: the authentic base prompt
(verbatim), the P5x-G Global Equity variant (low-resource, offline-first),
the P6x-AM Advanced Markets variant (US & Asia-Pacific), a jurisdiction
matrix (HIPAA · GDPR · NDPR · Kenya DPA · India DPDP · LGPD · PDPL · PIPL ·
APPI · tribal/community consent), architecture, methodology, merits, and
guidance. Jurisdiction compliance notes: [../compliance/](../compliance/).
Open-model-only constraint in the Global Equity variants: locally hosted
open-weight models; no closed-API processing of PHI.
